Chase's Contact Manger
Version 1.0.0
---

Features
---
+ Adding a contact.
+ Deleting a contact.
+ Editing a contact.
+ Searching for a contact via name.
+ Importing contact data via C.S.V. file.
+ Exporting contact data to a C.S.V. file.
---

Requirements
---
+ Windows
+ Java 1.1 - Java 26.0.2 (The latest version of Java)
