Chase's Contact Manager  
Version 1.0.0
---

## Features
+ Adding a contact.
+ Deleting a contact.
+ Editing a contact.
+ Searching for a contact via name.
+ Importing contact data via CSV file.
+ Exporting contact data to a CSV file.

## Requirements
+ Java Development Kit (JDK) with desktop support
+ Gson 2.14.0

## Dependencies

This project uses Gson version 2.14.0 to handle JSON data.

## Running the Project

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Ensure Gson 2.14.0 is configured as a project dependency.
4. Build and run the application from src/Main.java.
